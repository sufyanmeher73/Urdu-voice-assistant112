# UrduVoiceAssistant — Free Cloud APK Build

This source package includes a GitHub Actions workflow at `.github/workflows/android-apk.yml`.
It builds the debug APK in GitHub's hosted runner and uploads the APK as a workflow artifact.

No Android Studio is required on the user's phone for the cloud build.
A GitHub account/repository is required, and GitHub's free usage limits/eligibility apply.
